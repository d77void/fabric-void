<h1 align="center">fabric-void</h1>

<p align="center">
  Fabric and Caffyne-Shell on Void!
</p>

---

To install the caffyne-shell pkg, you will need to install fabric-cli as well; fabric is not needed because caffyne-shell provides it by default.

After installing caffyne-shell please:

```
cp -r /etc/xdg/caffyne-shell ~/.config/
```

Now you can run this wayland simple and beautifull shell typing or adding it to your config of Hyprland, Niri or MangoWC.

```
~/.config/caffyne-shell/./start.sh
```

Hope you guys and gals enjoy.
